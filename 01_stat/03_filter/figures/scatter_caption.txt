─────────────────────────────────────────────────────────────────────────────
WHAT THIS FIGURE SHOWS
─────────────────────────────────────────────────────────────────────────────
The STAT k-mer signal space for all ~608k screened runs, showing where the
two search modes draw their retention gates and which BioSamples pass them.
Each coloured point is one biosample-representative run; grey points are
gate-fail runs from the same mode shown as context.

─────────────────────────────────────────────────────────────────────────────
AXES (both panels)
─────────────────────────────────────────────────────────────────────────────
X — Host k-mers (%): Viridiplantae total_count / analyzed × 100
    (STAT kingdom-level count, consistent with the actual gate logic)
Y — Pathogen k-mers (%): (Fungi + Oomycota + Nematoda) total_count /
    analyzed × 100
Both axes log10, 0.05–100% range (floor applied to plot zeros on log scale).
Dashed gate line marks the 1% threshold for each mode.

─────────────────────────────────────────────────────────────────────────────
PANEL A — MAL (microbe-as-library)
─────────────────────────────────────────────────────────────────────────────
Library organism: PHI-base plant pathogen (fungi, oomycetes, nematodes,
bacteria). Gate: Viridiplantae reads ≥ 1% (confirms the sample is in planta).
Gate line: vertical dashed at x = 1%.

Colours:
  Light blue — single pathogen detected (co_infection_flag = "single")
  Dark blue  — co-infected (multi_species or multi_kingdom)
Grey background: MAL runs that failed the host ≥ 1% gate.

Interpretation: Points to the right of the gate line have confirmed plant
signal; co-infected runs (dark blue) are distributed across the host signal
range. The horizontal spread of grey points shows the majority of MAL runs
have minimal Viridiplantae signal — consistent with pure pathogen cultures,
misclassified library source, or the STAT Dikarya stall (rusts and similar
Basidiomycota systematically underrepresented in STAT; see pilot figures).

─────────────────────────────────────────────────────────────────────────────
PANEL B — HAL (host-as-library)
─────────────────────────────────────────────────────────────────────────────
Library organism: PHI-base plant host species. Gate: any PHI-base eukaryotic
pathogen ≥ 1% (detects cryptic co-infector in what appears to be a pure host
transcriptome). Gate line: horizontal dashed at y = 1%.

Colours:
  Light green — single pathogen detected
  Dark green  — co-infected
Grey background: HAL runs that failed the pathogen ≥ 1% gate.

Interpretation: Most gate-pass HAL points cluster in the upper-right (high
host signal + detectable pathogen), consistent with in-planta field samples.
Gate-fail grey points have near-zero pathogen signal — likely controlled lab
samples or runs with very low pathogen titre.

─────────────────────────────────────────────────────────────────────────────
CAVEATS
─────────────────────────────────────────────────────────────────────────────
- Virus counts are excluded from the Y axis (HAL gate uses Fungi + Oomycota +
  Nematoda only; viruses use a separate STAT kingdom and higher threshold).
- Log floor at 0.05% means zero-signal points are plotted at x or y = 0.05
  rather than off-scale; they are not true detections.
- STAT Dikarya stall: rust-dominated MAL runs can have genuinely high pathogen
  abundance but appear at y ≈ 0.05 (floor) because STAT does not represent
  Basidiomycota well. These contribute to the grey cloud at low host signal
  in Panel A. The Kraken2 pipeline (kraken branch) is designed to recover them.
