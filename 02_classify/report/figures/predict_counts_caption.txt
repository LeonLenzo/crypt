FULL CAPTION

Vipsania, an unsupervised deep ab-initio gene finder, run on 60 fungal assemblies that
ALREADY carry an NCBI gene model, so the annotation can serve as ground truth. Each point
is one assembly. The dashed line in panels a and b is 1:1, and both axes of each of those
panels share a single range and break set, so a point's distance from the diagonal is
read directly rather than inferred.

THREE INCREASINGLY STRICT QUESTIONS, which is the structure of the figure:

  a  Does prediction call the same NUMBER of CDS?  median ratio 1.01
     (29 under-call, 31 over-call)
  b  The same AMOUNT of sequence?                  median ratio 1.03
     (13 under, 47 over)
  c  The SAME sequence?    median recall 0.962, precision 0.944

PANEL c IS THE POINT. Agreement in a and b is necessary and nowhere near sufficient:
identical totals are perfectly consistent with entirely different sequence. Only k-mer
containment tests identity, which is why the benchmark does not stop at counting genes.
Recall is the fraction of the TRUE CDS k-mer space the prediction recovers -- too low and
the species cannot be detected when present. Precision is the fraction of the PREDICTED
k-mer space that is real CDS -- too low and the invented sequence inflates the taxon's
minimizer count, which is the denominator every coverage figure in 05_detect divides by.
Containment is estimated from FracMinHash sketches, k=31, scaled=200, the same parameters
as the saturation and depth-bias tables, so the numbers are comparable to those.

COUNTS IN PANEL a ARE FAIR TO COMPARE, which is not obvious: NCBI's cds_from_genomic.fna
holds one entry per CDS INCLUDING isoforms, while vipsania writes one per predicted gene.
Measured rather than assumed -- NCBI CDS entries divided by NCBI's own protein-coding gene
count has median 1.000 across the 60 assemblies where both are known, and only
4 exceed 1.10. Fungal isoform inflation is negligible at this scale.

POINT FILL is genome size in Mb on a log10 scale, 8 to 143 Mb across the figure,
viridis reversed so dark is large. Colourbar breaks: 10, 20, 40, 80, 160.
Genome size is the variable that predicts the deviation: it correlates -0.53 with both
recall and precision (r2 = 0.28). The mechanism is transposons. Ab-initio prediction calls
genes inside repeats, large fungal genomes are large mostly because of repeats, and the
failure therefore shows up as OVER-prediction with intact recall -- the signature is a
point that sits above the diagonal in a and b and bottom-right in c.

AXIS RANGES, shared within each panel:
  a   0 to 30,000 CDS, LINEAR, drawn in units of 10,000 so the numerals read
      0, 1, 2, 3; axis titles carry the x 10,000.
  b   0 to 40 Mb, LINEAR, breaks every 10
  c   0.40 to 1.00 on BOTH axes, breaks every 0.2; dotted guides at 0.90 on both
      Linear and zero-based throughout: the ranges span under one order of magnitude,
      so log buys nothing, and a zero origin makes the 1:1 line a true identity line.

WHAT THIS FIGURE DOES NOT SHOW. These 60 species already have gene models and are already
in db_v4, so prediction adds nothing for them -- the panel exists only to calibrate how
far a predictor can be trusted. Whether prediction is WORTH running on the species that
lack a model is a separate measurement, of how much of the predicted k-mer space is new
to db_v4, and is not in this figure.
