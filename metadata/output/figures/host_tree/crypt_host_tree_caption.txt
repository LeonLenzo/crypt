─────────────────────────────────────────────────────────────────────────────
WHAT THIS FIGURE SHOWS
─────────────────────────────────────────────────────────────────────────────
A fan-layout phylogenetic tree of plant host species with confirmed runs
in the crypt pipeline (both MAL and HAL modes). Radial bars show the number
of BioSamples with single pathogen vs co-infection detections per host.

─────────────────────────────────────────────────────────────────────────────
TREE CONSTRUCTION
─────────────────────────────────────────────────────────────────────────────
Topology: NCBI taxonomy cladogram via ete3 NCBITaxa (local SQLite). Built
from species names resolved from the `host` column of runs.tsv (STAT
Viridiplantae leaf species). Branch lengths = None (cladogram, equal branch
lengths; topology only, no molecular clock).
Tips: all host species with ≥ 1 confirmed BioSample (MIN_RUNS = 1).
Layout: fan, open.angle = 20°.

─────────────────────────────────────────────────────────────────────────────
BAR LAYERS
─────────────────────────────────────────────────────────────────────────────
Two bars per tip, drawn radially outward from the tree:
  Green (#27ae60) — n_single: BioSamples with single pathogen detected
  Orange (#e67e22) — n_multi: BioSamples with co-infection (multi_species or
                     multi_kingdom flag)
Bar length: log10 scale (BAR_UNIT = 7 x-units per log10). Reference circles
at 10⁰, 10¹, 10², 10³ (1, 10, 100, 1000 BioSamples).
Unit: biosample-representative BioSamples from runs.tsv (both modes).

─────────────────────────────────────────────────────────────────────────────
WHAT TO LOOK FOR
─────────────────────────────────────────────────────────────────────────────
- Phylogenetic clustering of co-infection susceptibility: if certain clades
  show consistently large orange bars, this suggests phylogenetic signal in
  host susceptibility — some plant lineages may be more prone to co-infection
  or more intensively sampled in field settings.
- Hosts with large orange bars relative to green suggest high co-infection
  rates (but see caveats on sequencing effort below).
- The tree topology groups hosts by NCBI taxonomy, so monocots, eudicots,
  and other lineages cluster together. Cereal crops (Poaceae) are identifiable
  as a dense cluster in the monocot branch.

─────────────────────────────────────────────────────────────────────────────
CAVEATS
─────────────────────────────────────────────────────────────────────────────
- Bar height reflects sequencing effort (total SRA runs) as much as true
  co-infection biology. Hosts with many SRA runs (wheat, rice, maize) will
  show large bars regardless of per-sample co-infection rate.
- Host species resolved only where STAT assigns Viridiplantae reads to a
  species-level name. Runs where STAT only reaches genus or broad clade
  (e.g. Poales, Viridiplantae) are excluded from host-specific counts.
- Both MAL and HAL combined; a single BioSample counted once only.
- co_infection_flag includes all confidence levels (same_genus_secondary
  not filtered). For a conservative view, use n_multi filtered to
  same_genus_secondary=False — this typically halves the co-infection count.
- Broad-clade host names excluded from the tree (no species-level tip to place
  in NCBI taxonomy); these runs still contribute to mode-level totals.
