─────────────────────────────────────────────────────────────────────────────
WHAT THIS FIGURE SHOWS
─────────────────────────────────────────────────────────────────────────────
A zoomed view of the largest connected component from the field HC guild
network, restricted to the cereal foliar pathogen cluster. Overlapping convex
hulls show which host plant species each pathogen was detected on, revealing
the host range overlap within the cluster.

─────────────────────────────────────────────────────────────────────────────
DATA ORIGIN
─────────────────────────────────────────────────────────────────────────────
Same filters as field_hc_network (biosample_representative, same_genus_
secondary=False, field setting). Nodes and edges from field_hc_nodes.tsv and
field_hc_edges.tsv. Host identity from field_hc_node_hosts.tsv (one row per
pathogen × host pair; host resolved from STAT Viridiplantae leaf species, with
named_host from biosample_kw.tsv as fallback for broad-clade STAT calls).

─────────────────────────────────────────────────────────────────────────────
NODE COLOURS
─────────────────────────────────────────────────────────────────────────────

Node size: proportional to total BioSamples (n_primary + n_secondary).

─────────────────────────────────────────────────────────────────────────────
HOST HULLS
─────────────────────────────────────────────────────────────────────────────
Each hull encloses nodes where that host plant was detected as the primary
STAT Viridiplantae species. Hull inclusion criteria:
  - Host must appear in HULL_WHITELIST (biologically credible for this cereal
    cluster: Triticum sp., Hordeum vulgare, Zea mays, Sorghum bicolor)
  - Host must span ≥ 3 distinct cluster nodes (MIN_HOST_NODES = 3)
  - At least 1 co-infection run per (pathogen, host) pair (MIN_HOST_RUNS = 1)
Aegilops tauschii remapped to Triticum aestivum in the hull layer — STAT
cannot distinguish Ae. tauschii (D-genome donor) from wheat D-subgenome reads.

─────────────────────────────────────────────────────────────────────────────
KEY FEATURES TO DISCUSS
─────────────────────────────────────────────────────────────────────────────
- The wheat hull (Triticum) is the largest, spanning the rust (Pucciniales)
  and Septoria (Capnodiales/Zymoseptoria) nodes — these are the dominant
  wheat foliar pathogens and frequently co-detected in field transcriptomics.
- Puccinia rusts (red nodes) co-occur with Zymoseptoria tritici and
  Alternaria spp. — biologically expected in field wheat.
- Barley (Hordeum) and maize (Zea) hulls where present show host-specific
  pathogen sub-communities that partially overlap the wheat community.
- wheat_cluster_plain.pdf is the same layout without hulls — useful for
  comparing node connectivity without the overlay.

─────────────────────────────────────────────────────────────────────────────
CAVEAT — Fusarium blind spot
─────────────────────────────────────────────────────────────────────────────
Fusarium is nearly absent from this network because 94% of Fusarium
co-infections are same-genus (multiple Fusarium species co-detected), so
nearly all are removed by the same_genus_secondary=False filter. Only ~6
Fusarium appearances survive the HC filter (2 as primary, 4 as secondary).
This is a real limitation: intra-genus co-infection is biologically common
in Fusarium, but the HC filter cannot distinguish it from k-mer ambiguity.
A same-genus-allowed view would be needed to capture Fusarium co-infections.
