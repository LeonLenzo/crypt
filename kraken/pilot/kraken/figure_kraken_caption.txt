─────────────────────────────────────────────────────────────────────────────
WHAT THIS FIGURE SHOWS
─────────────────────────────────────────────────────────────────────────────
A diagnostic comparison of three independent methods for detecting eukaryotic
pathogens in field RNA-seq runs where the pathogen was the library organism
(microbe-as-library, MAL). The pilot was designed to evaluate whether NCBI
STAT k-mer taxonomy is reliable as a retention gate for the crypt pipeline.

─────────────────────────────────────────────────────────────────────────────
DESIGN
─────────────────────────────────────────────────────────────────────────────
45 SRA runs × 3 organisms × 3 STAT signal tiers (5 runs per cell):
  - P. striiformis f. sp. tritici (PST) — wheat yellow rust, Basidiomycota
  - P. graminis f. sp. tritici (PGT)    — wheat stem rust, Basidiomycota
  - Pyricularia oryzae (POR)            — rice blast, Ascomycota

Tiers based on STAT eukaryotic pathogen signal:
  - Zero  (circles):   STAT euk_pct = 0.0%
  - Low   (triangles): STAT euk_pct 0–1%
  - High  (squares):   STAT euk_pct ≥ 1%

500k reads per run streamed from ENA FTP (curl | gunzip | head).

Methods:
  - STAT: NCBI pre-computed k-mer taxonomy (euk_pct = % reads assigned to
          any eukaryotic taxon in the STAT database)
  - Kallisto: pseudo-alignment to RNA transcriptome FASTA (GCF accessions:
          PST GCF_021901695.1, PGT GCF_000149925.1, POR GCF_000002495.2)
  - Kraken2: k-mer classification against a mini database built from the same
          three RNA FASTA references; metric = pct_classified (total reads
          assigned to any of the three organisms; see PGT note below);
          --confidence 0.1

─────────────────────────────────────────────────────────────────────────────
PANEL A — STAT vs kallisto
─────────────────────────────────────────────────────────────────────────────
Axes: STAT eukaryotic pathogen % (x) vs kallisto pseudoalignment rate (y),
both log10 scale (log1p transform; breaks at 1%, 10%, 100%).
Dashed line = perfect agreement.

Key finding — PST Dikarya stall:
STAT reports 0.0% eukaryotic reads for ALL 15 PST runs regardless of true
pathogen abundance. Two zero-tier runs (annotated) have kallisto rates of
63.2% (ERR4421882) and 31.1% (ERR4315255) — i.e. the majority of reads are
PST transcripts but STAT assigns zero eukaryotic signal. This is the "Dikarya
stall": rust fungi (Basidiomycota, subkingdom Dikarya) have poor k-mer
representation in the STAT eukaryotic database, causing systematic
false-negatives. The same pattern holds for PST low-tier runs (0.12–0.71%
STAT, 2.3–65.4% kallisto).

PGT and POR:
Both show reasonable STAT–kallisto agreement. STAT does detect Puccinia
graminis and Pyricularia oryzae, suggesting the stall is specific to or more
severe in P. striiformis.

─────────────────────────────────────────────────────────────────────────────
PANEL B — kallisto vs Kraken2
─────────────────────────────────────────────────────────────────────────────
Axes: kallisto pseudoalignment rate (x) vs Kraken2 pct_classified (y),
same log10 scale. Dashed line = perfect agreement.

Key finding — Kraken2 validates kallisto:
PST (orange) and POR (green) points cluster tightly along the diagonal across
all tiers, confirming that Kraken2 and kallisto give consistent estimates of
pathogen abundance. This cross-validates both methods independently.

PGT same-genus cross-classification (annotated purple points):
Kraken2 pgt_pct = 0.0 for all PGT runs. Instead, PGT reads classify to
pst_pct, because PST and PGT are both Puccinia spp. and share a large
fraction of transcriptomic k-mers. Kraken2's LCA algorithm promotes ambiguous
k-mers up the taxonomy tree; with the more complete PST RNA ref dominating,
PGT reads are assigned to PST at species level. The metric plotted (y-axis)
is pct_classified (PST + PGT + POR combined), which correctly captures the
total rust signal for PGT samples even though species resolution fails.
PGT high-tier points remain below the diagonal (annotated) because kallisto
aligns specifically to the PGT transcriptome while Kraken2 splits the signal
between the PST node and the Puccinia LCA, losing some reads to the LCA bin.

This same-genus ambiguity is expected behaviour and mirrors the
same_genus_secondary issue already flagged in the STAT pipeline (where 65% of
secondary detections are same-genus, concentrated in Puccinia rusts). For the
production Setonix Kraken2 run, same-genus co-infection pairs will be
filtered by the same_genus_secondary flag as in the existing pipeline.

─────────────────────────────────────────────────────────────────────────────
CAVEATS AND LIMITATIONS
─────────────────────────────────────────────────────────────────────────────
1. RNA refs (pilot only): the Kraken2 pilot database was built from
   transcriptome FASTAs to reuse existing kallisto references. The production
   Setonix database (kraken_build.py) uses full genomic FASTAs for all
   PHI-base eukaryotic pathogen seeds, which provides broader k-mer coverage
   and is not limited to annotated transcripts.

2. Three-species database: the mini pilot DB contains only PST, PGT, POR.
   Cross-classification between closely related species will look different in
   the full database where genus-level LCA nodes are populated by many species,
   reducing same-genus false assignments.

3. 500k reads per run: sufficient for detection at the thresholds used
   (≥0.5%) but subsampled from full runs which range from 1M to 160M reads.
   Production Setonix run also uses 500k reads for consistency and speed.

4. PST zero-tier note: even at 0% STAT euk_pct, some PST zero-tier runs show
   low Kraken2/kallisto signal (<1%), consistent with genuine low-abundance or
   absent pathogen in those samples. The two annotated outliers (ERR4421882,
   ERR4315255) are from the same BioProject (PRJEB39756) and represent
   genuine high-abundance PST libraries that STAT completely misses.

─────────────────────────────────────────────────────────────────────────────
IMPLICATIONS FOR PIPELINE
─────────────────────────────────────────────────────────────────────────────
The STAT Dikarya stall means an unknown proportion of MAL runs with rust
pathogens as the library organism have been silently excluded by the current
STAT-based gate in 02_filter_runs.py. Kraken2 classification of all ~593k
step-01 runs on Setonix will recover these runs and enable a direct STAT vs
Kraken2 comparison as a paper figure.

For co-infection detection specifically: the stall affects STAT's ability to
detect the library organism, not necessarily secondary co-infecting organisms.
But runs where STAT misses the primary organism (euk_pct = 0) are currently
failing the MAL gate (Viridiplantae ≥ 1%) regardless of whether any co-
infectors are present — so the gate failure rate may be understated.
