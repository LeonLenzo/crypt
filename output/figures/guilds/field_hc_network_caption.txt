─────────────────────────────────────────────────────────────────────────────
WHAT THIS FIGURE SHOWS
─────────────────────────────────────────────────────────────────────────────
A co-occurrence network of plant pathogens co-detected in field RNA-seq
samples. Each node is a pathogen; edges connect pathogen pairs that appeared
together in at least one BioSample. This is the most conservative view of the
co-infection data: field samples only, high-confidence co-infections only.

─────────────────────────────────────────────────────────────────────────────
FILTERS APPLIED (three stacked)
─────────────────────────────────────────────────────────────────────────────
1. biosample_representative = True  — one row per biological sample
2. same_genus_secondary = False     — excludes same-genus co-detections
   (removes ambiguous cases where closely related species share k-mers,
   especially Puccinia rust pairs; see CLAUDE.md k-mer specificity section)
3. llm_study_setting = "field"      — LLM-classified field studies only
   (excludes controlled lab experiments and samples with unclear provenance)

─────────────────────────────────────────────────────────────────────────────
NETWORK STRUCTURE
─────────────────────────────────────────────────────────────────────────────
Nodes: 157 pathogens (header row excluded from wc count above)
Edges: 177 co-infection pairs
Node size: proportional to total BioSamples in which that pathogen appears
           (n_primary + n_secondary)
Edge weight: number of BioSamples sharing that co-infection pair
Node colour: kingdom (Fungi=#d35400, Bacteria=#2980b9, Viruses=#c0392b,
             Oomycota=#8e44ad, Nematoda=#27ae60, Unknown=#95a5a6)
Labels shown for nodes with total detections ≥ 4 (LABEL_THRESHOLD).
Layout: Fruchterman-Reingold (force-directed), seed = 42.

─────────────────────────────────────────────────────────────────────────────
KEY FEATURES TO DISCUSS
─────────────────────────────────────────────────────────────────────────────
- The network is not fully connected — isolated dyads and small clusters
  reflect host-specific pathogen communities (e.g. cereal rusts cluster
  separately from solanaceous pathogens).
- The largest connected component is dominated by cereal foliar pathogens
  (see wheat_cluster.pdf for the zoomed view with host hulls).
- Broad-clade host names (Viridiplantae, Poales etc.) are excluded from host
  resolution; runs where STAT only assigns plant reads to a broad clade are
  retained in the network but their host is unresolved.
- same_genus_secondary=False removes ~69% of co-infected BioSamples (most of
  which are Puccinia rust pairs). The remaining ~31% are cross-genus, cross-
  kingdom, or cross-family detections with the highest biological credibility.
